# Tiny Task Tracker

A small, dependency-free task tracker you can run in any modern browser. It starts with a `vvv` task. Add tasks, mark them complete, filter the list, and come back later without losing your tasks.

## Run it

Open `index.html` in your browser. Tasks are saved in that browser's local storage.

## Git practice ideas

Try these in any order:

1. Check the project status with `git status`.
2. Stage only `README.md` with `git add README.md`, then inspect the staged changes with `git diff --staged`.
3. Commit the README, then commit the app files separately.
4. Create a branch called `add-due-dates` and add a due-date field to new tasks.
5. Make a change on another branch and practice merging it.
6. Use `git log --oneline` to review your commits.
7. Change something by mistake and practice restoring just that file.

## Project files

- `index.html` — page structure
- `styles.css` — layout and styling
- `app.js` — task behavior and browser storage
